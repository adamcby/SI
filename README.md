# iPhone Duo · SI marketing et ventes

Prototype du système d'information marketing et ventes d'Apple pour le lancement de l'iPhone Duo.
Projet de TD de Fondamentaux des systèmes d'information, L2 Gestion et Management, IAE Lyon (2026-2027), groupe 12.

**Site : https://adamcby.github.io/SI/**

- Côté client : la boutique en ligne (précommande), le compte client et le questionnaire de satisfaction par QR code.
- Côté entreprise : les écrans des six profils de salariés (vente, relation client, marketing, stock, qualité, finance) et l'espace de deux partenaires externes (banque, distributeur).
- Un journal des échanges entre services, avec les numéros de flux des tableaux A1 à A3 du dossier, et le suivi d'une commande ou d'un avis étape par étape dans son processus.
- Les deux processus du dossier fonctionnent de bout en bout : précommande → paiement → réservation → confirmation, et avis → défaut → analyse → coût de garantie → réponse au client.

Les clients, les commandes et les chiffres internes sont fictifs. Les actions faites sur le site sont enregistrées seulement dans le navigateur de la personne qui l'utilise. Projet universitaire, sans lien avec Apple Inc.

Le site est fait de pages fixes (HTML, CSS et JavaScript), sans serveur ni installation. L'ancienne application en Python est conservée dans la branche `ancien-prototype`.
